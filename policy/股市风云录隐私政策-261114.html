温馨提示

欢迎您使用《股市风云录》！我们非常重视保护您的个人信息和隐私。本政策说明我们如何收集、使用、存储您的个人信息，以及您享有的相关权利。请您仔细阅读并充分理解以下要点：

《股市风云录》是一款以本地存档为主的游戏。我们不架设用于存储您游戏数据的自有服务器，您的游戏进度默认只保存在您的设备本地；只有在您主动登录后，存档才会上传至您所用渠道提供的云端，用于跨设备接续与备份。

为向您提供账号登录与云存档、实名认证与防沉迷、数据统计、更新唤起与广告展示等服务，我们接入了必要的第三方 SDK。只有在您于首次启动的隐私政策弹窗中点击「同意」之后，我们才会初始化此类 SDK。您点击「拒绝」时，我们不会初始化任何会收集个人信息的 SDK，登录与云存档不可用，您仍可离线游玩。

游戏内广告均由第三方广告服务商提供，观看完全自愿。不观看广告只会失去对应的可选加成，不影响正常交易、结算与游戏进度。

您可以访问、更正、删除您的个人信息，也可以撤回授权同意、投诉举报。我们已采取符合业界标准的安全防护措施保护您的个人信息。

如您是未成年人，请您和您的监护人仔细阅读本政策，并在征得监护人授权同意的前提下使用我们的服务或向我们提供个人信息。

如您同意本政策，请您在游戏内隐私政策弹窗中点击「同意」开始使用我们的产品和服务；您也可随时在游戏内「设置 → 隐私政策」中查看全文、重新确认或撤回同意。

一、我们如何收集和使用您的个人信息

（一）我们如何收集您的个人信息

在您使用《股市风云录》过程中，我们会按照如下方式收集您的个人信息：

游戏存档

《股市风云录》无需注册账号即可游玩。您的游戏进度与设置（长期进度与解锁档、单局持仓与资金流水、语言与音效设置、引导完成状态等）以存档形式保存在您的设备本地（应用内本地存储）。如您清除应用数据，本地存档将被删除且无法恢复。

账号登录与云存档（可选）

登录功能为可选：不登录也可完整游玩。您选择登录时，我们通过所接入的渠道账号 SDK 获取账号标识（openId、unionId），并在您授权「公开资料」后获取昵称与头像，仅用于在游戏内显示账号状态、区分存档归属，以及以账号 openId 作为实名认证的标识以便跨设备接续防沉迷状态。

登录后，游戏会把您的存档（长期进度、当前对局与设置三类内容）上传至该渠道提供的云端存档服务，形成云端存档，用于换设备接续与备份恢复。云端存档内容与本地存档一致，不含您的姓名、身份证件号码等实名信息。云存档为单账号单槽位，同名存档会被覆盖更新。

云端存档的同步遵循以下规则：本地进度优先，登录时不会直接用云端覆盖本地；仅当云端进度严格高于本地时，游戏会提示您选择以哪一方为准；为防止进度回退，当已知的云端进度高于本地时，游戏不会上传本地存档。退出登录后本机仍可离线游玩，云端存档保留。

实名认证与防沉迷

根据国家关于防止未成年人沉迷网络游戏的规定，您在使用本游戏前需完成实名认证。我们不自行收集您的姓名、身份证件类型、身份证件号码等实名信息；实名认证与游戏时长、时段限制由您获取本游戏所使用渠道提供的合规服务完成，请您遵循相应提示。我们仅接收「是否通过认证」「是否处于可游玩时段」等状态结果，用于放行或拦截游戏。

设备标识符与广告信息

经您同意本政策后，我们接入的第三方广告 SDK 可能收集您的设备标识符（OAID、Android ID）、网络信息（IP 地址）、应用安装列表、设备传感器信息、设备型号与系统版本，以及广告的曝光、点击与完播记录，用于广告展示、广告归因与投放效果统计。上述信息的处理规则详见本政策第五章。

为读取 OAID，Android 安装包会包含设备厂商 OAID 服务所需的普通权限（如 com.asus.msa.SupplementaryDID.ACCESS、freemme.permission.msa），仅用于获取匿名设备标识符，不涉及您的其他信息。

即使您已同意本政策，广告 SDK 对位置、电话状态、OAID、传感器等采集项也以最小必要为限，且 BSSID、SSID 与设备 MAC 地址始终不采集。

游戏内广告及其奖励

游戏内共设 7 处激励视频与 2 处插屏广告。激励视频对应的可选加成为：抽签时提高起始资金、重抽本金区间、破产后复活入场、追保期限延期、结算资金加成、获取一条内幕情报、临时提高单票融资上限；插屏广告出现在「返回首页」与「长时间无操作」两种时机，并有频次限制（首次进入主界面不展示、启动后 60 秒内不展示、每次展示后 60 秒内不再展示）。

观看激励视频期间游戏行情会暂停，广告结束后继续；未完整观看则不发放对应加成，但游戏可正常继续。是否观看由您自行决定，我们不设强制观看。

充值消费

《股市风云录》当前未开通游戏内充值功能，我们不收集您的支付信息。如后续开通，我们将依据相关法律法规处理您的交易信息，并在本政策中另行说明。

保障服务安全

本游戏主体在您的设备本地运行，我们不通过自有服务器收集您的设备标识符、IP 地址、访问日期与时间等日志信息。使用账号登录与云存档、实名认证、数据统计、更新唤起与广告等在线功能时，相关连接与日志信息由所接入的第三方 SDK 按其规则处理。

（三）我们如何使用您的个人信息

我们会为实现本政策所述目的，在必要范围内使用所收集的个人信息，包括：提供游戏功能与存档、完成实名认证与防沉迷校验、保障网络与服务安全、展示广告并统计投放效果。

我们会对服务使用情况进行统计，并可能与第三方共享不包含任何身份识别信息的统计结果，用于产品开发、体验优化与安全保障。

当我们要将您的个人信息用于本政策未载明的其他用途时，会事先征求您的同意。

（四）无需征得授权的例外

根据相关法律法规及国家标准，以下情形中我们可能收集、使用您的个人信息而无需征求您的授权同意：

  • 与我们履行法律法规规定的义务相关的；
  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与刑事侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
  • 所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
  • 根据个人信息主体要求签订和履行合同所必需的；
  • 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
  • 维护所提供产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

二、我们如何使用本地存储与同类技术

《股市风云录》不使用 Cookies 进行广告追踪或用户画像。为实现存档功能，我们会在您的设备上使用本地存储保存三类内容：长期进度（解锁档、成就、引导状态）、单局进度（持仓、资金流水、当日状态）与本地设置（语言、音效、倍速）。上述内容不包含您的身份识别信息，仅用于实现游戏功能。

您可以随时通过清除应用数据（Android 系统设置 → 应用 → 清除数据）或在浏览器中清除站点数据的方式删除上述内容。删除后游戏进度将无法恢复。本地存储中还会保存隐私同意的选择结果、登录账号标识与云端进度快照，用于避免重复询问、恢复登录展示与判断同步方向；清除应用数据会同时移除这些记录。

如您已登录并启用云存档，存档副本另存于渠道云端（见本政策第三章与第五章），清除本地数据不会自动删除云端存档。

三、我们如何保存您的个人信息

《股市风云录》未架设自有服务器，游戏进度默认仅保存在您的设备本地。您登录并启用云存档时，存档副本由所接入的渠道云端存档服务保存，保存位置、保存期限与删除方式由该渠道按其隐私政策与存储规则处理；我们不将该副本转存至自有服务器。使用实名认证、数据统计与广告等在线功能时，相关信息同样由所接入的第三方 SDK 按其隐私政策与存储规则处理；我们仅在实现功能所必需的期限内保留通过 SDK 获得的状态结果，超出期限后将删除或匿名化处理。

我们原则上在中华人民共和国境内处理您的个人信息。如确需向境外提供，我们将依法履行告知、取得单独同意及安全评估等义务。

四、我们如何共享、转让、公开披露您的个人信息

委托处理

如我们委托第三方服务提供商处理您的个人信息（如实名认证与防沉迷校验、数据统计、广告投放），该等委托处理受本政策所声明目的的约束，我们会以合同方式对受托方进行监督，要求其按照我们的要求、本政策及相关法律法规处理个人信息。

共享

除为实现账号登录与云存档、实名认证与防沉迷、数据统计、更新唤起、成就与广告展示等功能，向本政策第五章所列第三方 SDK 提供必要信息外，我们不会与其他第三方共享您的个人信息。以下情形除外：

  • 事先获得您明确的同意或授权；
  • 根据适用的法律法规规定，或按照政府主管部门的强制性要求进行提供；
  • 为实现服务所必需，与我们的业务合作伙伴共享。

转让

我们不会将您的个人信息转让给任何公司、组织和个人。但在涉及合并、收购、资产转让或破产清算且涉及个人信息转让时，我们会向您告知有关情况，并要求新的持有方继续受本政策约束，否则将要求其重新取得您的授权同意。

公开披露

我们不会公开披露您的个人信息，但法律法规另有规定或取得您单独同意的情形除外。

例外情况

根据相关法律及国家标准，以下情形中我们可能共享、转让、公开披露个人信息而无需事先征得您的授权同意：

  • 与我们履行法律法规规定的义务相关的；
  • 与国家安全、国防安全直接相关的；
  • 与公共安全、公共卫生、重大公共利益直接相关的；
  • 与刑事侦查、起诉、审判和执行判决等直接相关的；
  • 出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
  • 个人信息主体或监护人自行向社会公众公开的个人信息；
  • 从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道。

请注意，若我们采取技术措施和其他必要措施处理个人信息，使数据接收方无法重新识别特定个人且不能复原，此类处理后的数据的共享、转让与公开披露无需另行通知并征得您的同意。

六、我们如何保护您的个人信息

我们采取行业通行的数据保护技术与管理措施，例如传输加密、访问控制、最小必要收集，以防止个人信息遭到未经授权的访问、披露、篡改、丢失或毁坏。

请您知悉，互联网环境并非百分之百安全。尽管我们会尽力保护您发送给我们的信息，但我们无法对超出我们可控范围的风险作出担保。

在发生个人信息安全事件后，我们将按照法律法规要求及时向您告知：事件基本情况与可能影响、我们已采取或将要采取的处置措施、您可自主防范与降低风险的建议、对您的补救措施等。难以逐一告知时，我们会采取合理有效的方式发布公告，并按监管部门要求上报处置情况。

七、您如何管理您的个人信息

访问及更正您的个人信息

您可以在游戏内「设置」界面查看并修改语言、音效、倍速等设置项；游戏进度可在游戏内的持仓、成就、纪录等界面查看。登录后，您可在「设置 → 账号与云存档」查看当前账号、云端同步状态，并可手动触发同步或退出登录。「设置 → 隐私政策」可查看本政策全文、查看或重新确认您的授权状态。账号资料（昵称、头像）由渠道方管理，如需更正请通过渠道的账号设置办理。

删除您的个人信息

您可以随时在设备系统设置中清除本游戏的应用数据，或在浏览器中清除相应站点数据，以删除全部本地存档。本地清除不会自动删除云端存档：如需删除云端存档，可在游戏内「设置 → 账号与云存档」退出登录后按本政策载明的方式联系我们，或通过渠道的账号与客服渠道申请删除。此外，在以下情形中，您也可以按本政策载明的方式向我们提出删除请求：
